## 書き方の決まり

* 冒頭の表に **日付・対象コード（コミット）・`PARAMETER_SET_VERSION`・シード・再現コマンド・生の出力ファイル** を書く。
* 本文は **目的 → 仮説 → 実験手順 → 結果 → 考察 → 限界 → 次に行うべきこと** の順。
* 数値には **単位** を付ける（%、pt（％ポイント）、blocks、ticks（20 ticks = 1 秒）、分）。
* 確率が **決定論的な計算値** か **サンプリングの割合** かを明記する。サンプリングなら n と平均 ± 標準偏差を書く。
* 表は列の意味と単位を見出しに書く。グラフ（Mermaid）には **軸の名前・単位・条件** をタイトルと軸ラベルに入れ、
  図の下に 1 行の説明を付ける。
* 生の出力はノートと同じ場所に `*.output.md` として残し、ノートの数値はそこから転記する。
* 一時的なスクリプトで測った場合も消さず、再実行できる形（Gradle タスクなど）で残す。
* 予想が外れたときは、外れた予想も仮説として残し、どう間違えたかを考察に書く。

## テンプレート

```markdown
# 実験ノート：<問い>

| 項目 | 内容 |
|---|---|
| 日付 | YYYY-MM-DD |
| 対象コード | <ブランチ>、コミット <hash> |
| パラメータ | PARAMETER_SET_VERSION = <n>、τ = <値>、シード <値>、条件 <条件> |
| 再現コマンド | `./gradlew ...` |
| 生の出力 | [`YYYY-MM-DD_<内容>.output.md`](...) |

## 1. 目的
## 2. 仮説
## 3. 実験手順
## 4. 結果
## 5. 考察
## 6. 限界
## 7. 次に行うべきこと
```
